# Design System: Dark Mode Protocol

## Theme: Deep Dark

- **Background Primary**: #0a0a0a (Deep Black)
- **Background Secondary**: #161616 (Card/Surface)
- **Border/Stroke**: #262626
- **Text Primary**: #ededed (High contrast)
- **Text Secondary**: #a1a1a1 (Muted)
- **Accent**: #3b82f6 (Electric Blue)

## Component Rules

- **Buttons**: Background Primary, Border 1px, Text Primary. Hover: Background Secondary.
- **Cards**: Background Secondary, Border 1px, Shadow: None.
- **Inputs**: Background Primary, Border 1px, Focus: Accent Border.
